## Sobre mí

Soy un desarrollador full-stack enfocado en arquitectura de sistemas, diseño de bases de datos y construcción de productos digitales desde cero. Me gusta convertir ideas ambiguas en software útil: interfaces modernas, APIs robustas, flujos de negocio, automatizaciones, paneles administrativos, integraciones de pago y despliegues listos para operar.

Trabajo con el stack completo: **Next.js / React**, **Node.js / FastAPI**, **PostgreSQL / MySQL**, **Docker**, servidores, APIs externas y herramientas de IA. Mi enfoque es simple: construir sistemas que se puedan usar, mantener y escalar.

## Ahora mismo estoy construyendo

- **[Passion Room](https://lmog.vercel.app/)** — plataforma e-commerce para restaurantes con pagos, WhatsApp Business, gestión de pedidos y operación completa.
- **IA-GENOMA** — app móvil con IA generativa en tiempo real usando React Native / Flutter.
- **Software Core Tenis** — sistema de gestión para restaurante/bar con Java Swing + MySQL.
- **Bot Dropshipping / DropshipMind Agent** — investigación de productos, análisis WINNER, ads spy, landings y automatización de fulfillment.
- **El Parche** — red social con funcionalidades de split-bill usando FastAPI, React y PostgreSQL.
- Explorando **facturación electrónica**, **ciberseguridad** e integraciones avanzadas con APIs.
- Creando contenido técnico para compartir procesos, aprendizajes y construcción real de software.

## Filosofía de trabajo

- Construir primero lo que entrega valor real.
- Diseñar bases de datos pensando en el negocio, no solo en tablas.
- Mantener APIs claras, predecibles y fáciles de consumir.
- Crear interfaces rápidas, limpias y enfocadas en la tarea.
- Automatizar lo repetitivo y medir lo importante.
- Aprender en público, iterar rápido y mejorar con cada entrega.
